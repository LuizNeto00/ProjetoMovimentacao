# ProjetoMovimentacao

Projeto de movimentação financeira utilizando HTML, CSS e JavaScript com o framework Vue e utilizando a biblioteca do Quasar, com backend com o framework Laravel.

# Projeto de Movimentação Financeira

## Como rodar o projeto?

Abra no Visual Studio Code tanto a pasta frontend e backend, após isso abra o terminal do VSCode e no frontend dê o comando `cd` nas pastas movimentacaofrontend e movimentacaobackend. Dessa forma, quando estiver dentro de **movimentacaofrontend** dê o comando `quasar dev`, ele vai gerar um link para que mostre todo o frontend. No entanto, antes de rodar o backend você precisa ter o **XAMPP** instalado, entre no **XAMPP** e dê **Start** nas opções **Apache** e **MySQL** respectivamente, tendo tudo isso feito e estando dentro de **movimentacaobackend** dê o comando `composer run dev` e ele também lhe mandará um link para rodar o backend.

## Requisitos para rodar o projeto

- Visual Sutido Code
- Framework Vue
- XAMPP
